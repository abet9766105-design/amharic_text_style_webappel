Amharic Text Style - web app (Flask).  Uses the same style engine (styles.py) as the Telegram bot.
Local:   pip install -r requirements.txt ; python app.py   ->  http://localhost:5000
Deploy:  see DEPLOY.txt
Ads:     Google AdSense via environment variables (ADSENSE_CLIENT, AD_SLOT_TOP, AD_SLOT_BOTTOM). No code change needed.
